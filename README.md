# 📱 Desarrollo de Aplicaciones Móviles

Repositorio de laboratorios y proyectos del curso de Desarrollo de Aplicaciones Móviles (Ciclo VIII) de la Universidad Tecnológica del Perú (UTP).

## 🛠️ Tecnologías y Herramientas
* **Framework:** React Native
* **Entorno:** Expo
* **Lenguaje:** JavaScript
* **Otras librerías:** Expo Camera, Expo Location, Expo Notifications, AsyncStorage.

## 📂 Índice de Laboratorios

A continuación se detallan los proyectos desarrollados semana a semana:

* **Semana 01 - 06:** Fundamentos de React Native, navegación, componentes e interfaces.
* **Semana 09:** [ShoppingList con AsyncStorage](./semana-09/ShoppingListUtp) - Persistencia de datos locales.
* **Semana 11:** [CameraApp](./semana-11/CameraApp) - Implementación de cámara y galería de fotos.
* **Semana 12:** [SensorsApp](./semana-12/SensorsApp) - Uso de acelerómetro y GPS en tiempo real.
* **Semana 13:** [PermissionsDemo](./semana-13-propuesto) - Solicitud y gestión de permisos del sistema (Cámara y Ubicación).
* **Semana 14:** [NotificationsDemo](./semana-14-notifications) - Implementación de notificaciones push locales.

## 🚀 Cómo ejecutar los proyectos localmente

1. Clona este repositorio en tu máquina local:
   ```bash
   git clone https://github.com/NicoleSL37/desarrollo-aplicaciones-moviles.git

2. Entra a la carpeta del repositorio:
    ```bash
    cd desarrollo-aplicaciones-moviles
3. Navega hacia el proyecto específico que deseas ejecutar (por ejemplo, el de la semana 1):
    ```bash
    cd semana-01/laboratorio-01
4. Instala las dependencias del proyecto:
    ```bash
    npm install
5. Inicia el servidor de Expo:
    ```bash
    npx expo start
